# NeoRifts (Fabric 1.20.1)

**Что делает мод**
- Блок **Runic Obsidian** (`neorifts:runic_obsidian`) — текстура 256×256.
- Авто‑спавн разлома: каждые **5 минут**, в радиусе **15–40** блоков от игрока, по Y **±5**, только на блок и не на воду.
- **ПКМ** по разлому запускает **3 волны** `Dokkebi` (3 → 4 → 5).
- Разлом исчезает через **5 минут** или если игрок дальше **100** блоков.
- Награда: **8 Emerald** с именем **KpopCoin** + **120 XP**.
- Усиление мобов от уровня игрока: каждые **10 уровней** → +5% урон, +10% HP, +2% скорость. При 10/20/30… уровне: «Мобы стали сильнее».

## Требования
- Minecraft **1.20.1**
- Fabric Loader **0.14.22**
- Fabric API **0.92.0+1.20.1**
- Java **17**

## Локальная сборка
```bash
./gradlew build
```
Готовый JAR появится в `build/libs/`.

## Команды
- `/rift create` — создать разлом рядом (если нет активного).
- `/rift force` — форс‑создать (для тестов).
- `/rift despawn` — закрыть текущий.

## GitHub Actions
В репозитории уже есть workflow `.github/workflows/build.yml`, который собирает мод на каждом пуше и публикует артефакт.
